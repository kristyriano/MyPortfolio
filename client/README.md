# Kristy Riano | Portfolio

Personal portfolio website built with React and Vite for COMP229 Web Application Development (Assignment 1) at Centennial College.

## Pages

- Home: welcome message, key results and services overview
- About Me: photo, short biography and link to my resume (PDF)
- Projects: six projects with image, role and outcome
- Education: academic qualifications with dates
- Services: the services I offer
- Contact: contact information and a contact form

## Technologies

- React
- React Router
- Vite
- CSS

## How to run it locally

1. Run: npm install
2. Run: npm run dev
3. Open http://localhost:5173 in the browser
